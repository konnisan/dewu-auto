# 得物自动报名 V1.4：详情复筛与执行设置实施计划

## 范围

依据已批准的 `2026-09-06-detail-screening-and-settings-design.md`，补全内容类型、达人要求、拍摄要求复筛，删除首页随机浏览循环，明确订阅提醒零点击，改为本轮完整记录列表，并清理面向用户的执行设置。本轮设备验证只使用演练模式。

## 步骤 1：建立可独立测试的详情规则

修改或新增：

- `TaskDetail.kt`
- `TaskEligibilityEvaluator.kt`
- 新增详情复筛策略对象（如需要）
- `TaskFilterVerifier.kt`
- `verify-filter.bat`

实施内容：

1. 解析详情顶部内容类型：仅图文、图文/视频、仅视频。
2. 解析达人要求与合作详情中的拍摄要求。
3. 实现强制露脸、允许上身不露脸替代、并列强制要求的语义判断。
4. 普通屏蔽词继续逐字段检查；“露脸”交给语义判断。
5. 为短路顺序和所有确认示例编写离线回归。

## 步骤 2：改造详情页面状态机

修改：

- `AutomationState.kt`
- `AutomationRuntime.kt`
- `AutomationController.kt`
- `DewuSelectors.kt`

实施内容：

1. 详情打开后先验证内容类型；仅视频立即返回。
2. 达人要求失败时立即返回，不再继续寻找拍摄要求。
3. 达人要求通过后，在详情页受限下滑并累计文本，直到读取拍摄要求。
4. 拍摄要求通过后才允许寻找“立即报名”。
5. 未识别内容类型、字段或页面边界时安全跳过，不推测、不报名。
6. 返回路径将当前任务加入已处理集合，避免重复打开。

## 步骤 3：订阅提醒零点击与单排序扫描

修改：

- `TaskCard.kt`
- `TaskCardParser.kt`
- `AutomationController.kt`
- `DewuSelectors.kt`

实施内容：

1. 单独识别“订阅提醒”卡片，记录“尚未上架”。
2. 候选操作只接受精确文字“报名”。
3. 一轮只使用用户选择的排序方式。
4. 当前排序从顶部扫描，达到最大下滑次数后结束；不再切换第二排序或进入首页作品。
5. 保留同页多个初筛通过任务逐个处理的逻辑。

## 步骤 4：全量运行记录模型与列表界面

修改或新增：

- `AutomationRuntime.kt`
- `PreviewTaskResult` 所在文件
- `MainActivity.kt`
- `activity_main.xml`
- 新增 RecyclerView 适配器与行布局（或使用等价的动态列表）

实施内容：

1. 运行时保存本轮全部任务记录，不截断为两条或四条。
2. 按任务签名更新已有记录，不重复追加。
3. 页面使用可滚动列表展示名称、金额、名额、内容类型、判断原因和处理状态。
4. 计数与记录列表保持一致。

## 步骤 5：精简设置并公开固定规则

修改：

- `AutomationConfig.kt`
- `AutomationPrefs.kt`
- `MainActivity.kt`
- `activity_main.xml`
- `strings.xml`

实施内容：

1. 保留类目、排序、金额、屏蔽词、样品规格、目标任务数和最大下滑次数。
2. 删除首页作品数、休息区间、图文滑动、视频停留、刷新等待等用户输入。
3. 页面刷新和重试时间改为内部策略常量。
4. 卡密移至独立授权区域。
5. 新增只读固定规则说明：仅视频跳过、必须露脸跳过、允许上身不露脸则通过、检查拍摄要求、订阅提醒不点击。
6. 保持最终确认按钮默认关闭且不持久化。

## 步骤 6：硬编码集中与静态检查

1. 页面文字集中在选择器对象。
2. 详情语义集中在复筛策略对象。
3. 超时、节流、重试和屏幕比例集中为命名常量。
4. 搜索业务关键词与裸坐标，确认不存在隐藏屏蔽词或 1080×2340 绝对定位。

## 步骤 7：本地验证与新设备安装

1. 运行 `verify-filter.bat`。
2. 运行 `gradlew.bat assembleDebug`。
3. APK 版本升级为 V1.4 测试版。
4. 安装到实体机 `XPLGL20511000040`，恢复无障碍服务。
5. 截图确认设置结构、固定规则、记录列表和“最终确认报名：未开启”。

## 步骤 8：新设备演练

1. 保持最终确认关闭。
2. 验证“订阅提醒”不被点击。
3. 验证仅视频任务进入详情后自动返回。
4. 验证允许上身不露脸的任务可继续到拍摄要求。
5. 验证拍摄要求被读取并写入记录。
6. 对通过任务走到不可取消弹窗，自动取消并返回列表。
7. 检查日志：演练计数增加、真实报名成功数为 0、最终确认点击数为 0。

真实报名只做静态路径和离线保护验证；除非用户在人工监督下另行指定当次数量，否则不点击最终确认。

## 完成标准

- 详情三阶段复筛与露脸语义回归全部通过。
- 订阅提醒不存在可达点击路径。
- 一轮、最大下滑次数和排序语义与界面说明一致。
- 本轮记录全部可见且去重更新。
- 无首页随机浏览及其无关设置。
- 演练真机流程不产生真实报名。
- APK、哈希、版本号和验证结果可交付。
