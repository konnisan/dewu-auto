# 真机驱动单次报名实施计划

1. 扩展配置、运行时和状态：单次实测模式、运行编号、当前任务、后置条件重试、最终确认锁、一次性令牌和等待操作员状态。
2. 增加结构化运行日志与节点动作记录；所有关键 WebView 点击改为“动作后等待页面标志”，连续三次无变化停止。
3. 改造排序、筛选、类目和任务卡解析，使用真机 UC WebView 节点与实际页面后置条件。
4. 改造详情、报名信息、规格和不可取消弹窗流程；到达最终确认弹窗后进入操作员闸门。
5. 在 APK 页面增加单次实测开关、闸门摘要和“允许本次最终确认”按钮；令牌绑定当前运行与任务，60 秒一次性消费。
6. 添加离线测试，构建并安装 APK；通过 ADB 逐状态采集日志、截图和 UI XML，先完成阶段 A。
7. 阶段 A 全部通过后签发令牌，完成一次真实报名；识别成功页后立即停止并保存证据。

实施期间不会提交包含地址等隐私的截图或 UI XML。任何未知弹窗、验证码、结果未知或最终确认锁异常都会立即停止。
