# 得物自动报名 V1 实施计划

1. 扩展配置、持久化、运行时指标和状态枚举：目标报名数、视频停留、两阶段排序、报名成功/失败、首页循环。
2. 新增任务详情解析器与报名表单辅助逻辑，并用离线验证器覆盖详情屏蔽词、规格和成功计数。
3. 将控制器升级为完整状态机：列表候选 → 详情复核 → 报名表单 → 不可撤销确认 → 成功验证 → 返回列表。
4. 实现两阶段排序、列表下滑上限、商单轮次完成后的首页作品浏览，以及再次从达人号商单快捷入口进入。
5. 将 Android 页面和 Playwright 原型升级为“得物自动报名 V1 / 循环与执行设置”，增加目标数、风险确认和报名指标。
6. 更新文案、版本与 README；运行离线测试、Playwright、Android 构建、静态安全检查。真实报名只在用户再次明确授权后验证。

实施保持 `AutomationController` 负责状态推进，解析和表单规则拆分为独立组件。报名类按钮只能从报名状态调用专用激活函数，普通页面激活函数继续拒绝报名与申请入驻文案。
