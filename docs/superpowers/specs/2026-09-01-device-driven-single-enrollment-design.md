# 得物自动报名：真机驱动单次报名迭代设计

## 目标

以达人号真机 `88Y0219911081250` 的实际得物 5.89.0 页面为唯一运行依据，验证并修正 APK 的完整自动化链路：进入商单、设置排序、设置产品类目、扫描任务、详情复筛、填写报名信息、确认一次不可撤销报名、识别成功页并停止。

本轮最多完成一次真实报名。真实报名成功后立即停止，不进入第二个任务。

## 当前问题

得物商单页使用 UC WebView。部分节点执行无障碍 `ACTION_CLICK` 时会返回成功，但网页没有产生变化；实测任务卡中的报名人数和截止时间会被拆为多个文本节点。因此，控制器不能把“动作调用成功”当作“页面动作成功”，必须通过下一页面的可见标志确认每个状态转换。

## 测试策略

测试分为两个阶段，共用同一套生产状态机。

### 阶段 A：可撤销前置验证

1. 启动 APK，校验无障碍、卡密、目标数和样品规格。
2. 进入得物达人号“我 → 商单”快捷入口。
3. 点击排序控件并以页面文字确认“最近发布”已生效。
4. 打开筛选面板，选择界面配置的产品类目，点击“确定”，并以筛选栏或任务刷新结果确认生效。
5. 扫描当前页真实任务卡，记录标题、奖励、报名人数、名额、截止时间、按钮文字及坐标。
6. 进入候选任务详情，读取达人要求、发布要求和合作方式，执行屏蔽词检查。
7. 进入确认报名信息页，验证已有收货地址并选择配置的样品规格。
8. 到达“报名后无法取消”的最终确认弹窗时暂停，保存证据并再次校验所有前置条件。

阶段 A 可以因代码修复重复执行，但不能点击最终确认。

### 操作员确认闸门

本轮 APK 增加“单次实测模式”。到达标准不可取消弹窗后，状态机进入 `AWAITING_OPERATOR_CONFIRMATION`，保持弹窗且不点击。APK 首页显示当前任务、详情复筛结果、地址/规格校验结果和“允许本次最终确认”按钮。

只有该按钮被明确点击后才签发一次性确认令牌，并重新拉起得物继续当前弹窗。令牌只对当前运行编号和当前任务签名有效，60 秒过期，读取后立即消费。重新启动应用、切换任务、弹窗消失或验证失败都会使令牌失效。正式循环模式不依赖该测试按钮；它仅用于本轮真机迭代保存唯一一次不可撤销机会。

### 阶段 B：一次不可撤销验证

仅当阶段 A 所有后置条件均通过时执行：

1. 获取进程内单次确认锁。
2. 消费与当前运行、当前任务匹配且未过期的一次性确认令牌。
3. 确认目标报名数固定为 1，当前成功数为 0，当前运行尚未触发过最终确认。
4. 确认弹窗同时包含“报名须知”和“报名后无法取消”，且存在精确文字“确认”的可见按钮。
5. 点击一次最终确认。
6. 只接受“已报名，待品牌方确认”或等价成功标志作为成功。
7. 保存成功页截图、节点和日志，停止状态机，不返回列表，不继续第二个任务。

若最终确认后无法判断结果，立即停止并标记为“结果未知”，禁止重试最终确认。

## 状态机后置条件

每个动作只有在检测到对应后置条件时才能推进：

| 动作 | 必须检测到的后置条件 |
| --- | --- |
| 点击商单 | 排序、奖励类型或产品类目筛选栏可见 |
| 打开排序 | 综合排序、最近发布、即将截止选项同时可见 |
| 选择最近发布 | 筛选栏当前排序文字变为最近发布 |
| 打开筛选 | 任务类型、综合排序、奖励类型、产品类目及确定按钮可见 |
| 选择类目并确定 | 筛选面板关闭且任务列表重新加载 |
| 点击任务报名 | 任务详情标志和立即报名按钮可见 |
| 点击立即报名 | 确认报名信息、收货地址、样品规格可见 |
| 提交报名信息 | 报名须知及报名后无法取消可见 |
| 允许本次最终确认 | 一次性令牌与当前运行、当前任务匹配且未过期 |
| 最终确认 | 明确的已报名待确认成功标志可见 |

调用返回成功但后置条件未出现，按失败处理，不推进状态。

## 点击策略

- 商单 WebView 中的筛选控件和报名控件只使用当前可见节点的真实屏幕坐标点击。
- 不使用固定任务坐标，不点击零尺寸、屏幕外或非精确文字节点。
- 排序入口允许点击文字节点右侧箭头区域；菜单选项、类目和确认按钮点击各自节点中心。
- 申请入驻、订阅提醒、验证码及未知弹窗不允许点击。
- 点击后在限定时间内轮询后置条件；连续三次无变化即停止。

## 任务解析与筛选

- 将 WebView 拆分的结构化短文本组合用于字段解析，例如 `报名 | ： | 38 | /40人` 组合为 `报名：38/40人`，`6 | 天 | 后截止` 组合为 `6天后截止`。
- 保留原始分段文字用于标题识别和屏蔽词匹配，避免字段组合污染标题。
- 列表初筛检查名额、截止状态、奖励区间和列表屏蔽词。
- 详情复筛检查任务详情、达人要求、发布要求和合作方式的全部可见文字。
- 样品规格不在列表卡阶段判断，只在确认报名信息页选择并验证。

## 可观测性与证据

每次运行生成唯一运行编号。每个状态变化记录：

- 当前状态、进入时间和已等待时间；
- 动作名称、目标文字、节点坐标；
- 动作前后页面标志；
- 当前任务签名与脱敏标题；
- 重试次数、停止原因；
- 最终确认锁是否已使用。

ADB 侧在关键状态保存截图、UI XML 和过滤后的 `DewuAuto` 日志。报名信息页证据可能包含地址等隐私，只保存在忽略目录，不提交、不在回复中展示。

## 安全停止条件

出现以下任一情况立即停止：

- 验证码、人机验证或风控页面；
- 申请入驻页面；
- 未知确认弹窗；
- 收货地址缺失或规格无法准确选择；
- 页面后置条件连续三次不成立；
- 最终确认锁已使用；
- 最终确认后结果未知；
- 报名成功数达到 1。

停止时保留当前页面，不自动猜测返回路径，便于人工检查。

## 验收标准

1. 真机日志证明排序和配置的产品类目均已实际生效。
2. 至少一张真实任务卡被正确解析，拆分字段验证通过。
3. 任务详情全部可见要求参与屏蔽词检查。
4. 地址与规格在提交前被明确验证。
5. 最终确认在一个运行中最多触发一次。
6. 成功页被识别后状态机立即停止，真实报名成功数为 1。
7. APK 不点击申请入驻、订阅提醒或验证码。

## 非目标

- 不实现多账号或批量设备控制。
- 不绕过验证码、平台风控或得物私有接口。
- 不在本轮验证报名成功后的继续循环；循环恢复将在单次完整链路稳定后单独测试。
