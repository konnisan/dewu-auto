# 得物任务筛选预演与界面优化设计

日期：2026-08-29

## 目标

在当前账号不是达人号、页面内容可能与达人账号不同的情况下，完成可安全演示的“品牌合作任务筛选预演”。应用可以进入品牌合作页面、解析可见任务、应用筛选规则并展示结果，但不得点击“报名”或“申请入驻”。后续更换达人账号时，报名流程可以复用本次形成的任务解析和筛选模块。

## 已确认环境

- 测试设备：HUAWEI STG-AL00，Android 12，1080 × 2154。
- 得物包名：`com.shizhuang.duapp`，测试版本 5.99.1。
- 可用入口：`我 → 创作中心 → 玩转收益区域的查看更多 → 品牌合作`。
- 品牌合作页为得物 `BrowserActivity`，无障碍节点能够暴露任务标题、人数、截止时间、奖励金额和报名文本。
- 参考 APK 0.0.20 中可确认的配置包括类目、排序、下滑次数、价格范围、排除词、样品规格和刷新间隔。参考包采用 Lua、OCR 和坐标自动化；新实现只提取其流程与筛选语义，不复制受保护源码，也不沿用高风险权限或脆弱的全局 OCR 操作方式。

## 安全边界

- 本阶段只读取得物页面的无障碍节点并执行进入页面、筛选菜单和列表滚动。
- 不点击“报名”“立即报名”“申请入驻”“确认报名”或任何提交类按钮。
- 检测到验证码、安全验证、人机验证或滑块验证时立即停止。
- 检测到“申请入驻”时，将当前账号标记为未具备达人入口并显示提示，不尝试申请。
- 任务卡片中出现“报名”只作为卡片定位标记，不能成为可执行动作。

## 界面方案

采用单页任务面板，优先保证手机上快速配置和明确反馈。

### 顶部状态

- 显示无障碍服务、得物安装状态和当前运行状态。
- 显示醒目的“仅筛选预演，不执行报名”安全标记。
- 在检测到“申请入驻”时显示账号资格提示，但不阻止用户查看已有的任务预览。

### 常用筛选

- 产品类目。
- 排序方式。
- 最低和最高奖励金额。
- 排除词，支持中文或英文逗号分隔，并兼容参考 APK 的 `##` 分隔格式。
- 样品规格关键词；为空时不限制，非空时要求任务卡片文本至少匹配一个规格词。

### 高级设置

- 最大列表下滑次数。
- 页面刷新等待范围。
- 首页浏览数量、作品滑动次数和轮次休息时间保留，但收纳到折叠区域。
- 卡密放入单独的授权区域，避免与筛选参数混排。

### 主操作与结果

- 主操作命名为“开始筛选预演”，停止操作命名为“停止预演”。
- 结果区显示已扫描、符合、排除和解析失败的数量。
- 展示最近任务及判断结果，至少包含标题、奖励、名额、截止状态和排除原因。
- 在无任务或节点结构变化时显示可理解的诊断信息，而不是静默滚动。

## 解析与筛选结构

### TaskCardParser

从报名文本节点的可点击祖先或任务卡片容器中收集文本，解析为结构化任务：

- 稳定签名。
- 标题。
- 奖励金额。
- 已报名人数和总名额。
- 截止状态或截止描述。
- 原始卡片文本。

解析器不持有 Android 界面状态之外的业务规则，便于用纯文本样本测试。

### TaskEligibilityEvaluator

按以下顺序给出是否符合及原因：

1. 名额已满则排除。
2. 已截止或不可报名则排除。
3. 命中排除词则排除。
4. 无法解析奖励金额且配置了有效价格限制时排除。
5. 奖励金额不在范围内则排除。
6. 配置了样品规格但任务文本未命中任何规格词时排除。
7. 其余任务标记为符合。

类目和排序由品牌合作页面的筛选控件应用，不再依赖任务标题进行二次推断。

### PreviewRuntime

运行时只记录扫描统计、最近结果、状态和诊断信息。它不持有任何报名动作，避免后续误调用现有报名状态。

## 页面进入与兼容策略

优先使用文字节点完成：

1. 识别得物首页并点击“我”或“我的”。
2. 在个人中心点击“创作中心”。
3. 在创作中心定位包含任务预览的“玩转收益”区域。
4. 点击该区域内的“查看更多”，避免误点其他同名入口。
5. 通过“品牌合作”标题和筛选项共同确认目标页面。

如果缺少直接商单入口，以上路径仍为默认入口。只有在文字节点无法点击且页面特征已充分确认时，才允许使用基于屏幕比例的局部坐标兜底。

## Playwright 预览

先制作一份独立的手机尺寸 HTML 原型，使用 Playwright 在 1080 × 2154 视口检查视觉层级和交互状态。原型只用于评审，不作为生产应用代码。评审通过后，将布局和状态样式转换为 Android 原生 Views/XML，保持现有工程技术栈。

## 错误处理

- 页面识别超时：停止预演并展示当前包名和可见文本摘要。
- 筛选菜单无法打开：有限次数重试后停止，不进行盲点坐标连击。
- 卡片解析失败：计入解析失败数量，保留脱敏后的可见文本摘要供调试。
- 账号仅出现“申请入驻”：显示资格提示并安全停止进入流程。
- 安全验证：立即停止，要求用户手动处理后重新开始。

## 验证

- 为任务文本解析、名额判断、价格范围、排除词和样品规格编写单元测试。
- 使用当前手机导出的真实节点文本作为测试样本，但不保存账号标识等无关信息。
- 编译 Debug APK 并安装到已连接设备。
- 真机验证从首页到品牌合作页的完整入口。
- 真机验证筛选预演期间不会触发报名或申请入驻。
- 使用 Playwright 截图评审优化后的界面，再验证对应 Android 原生界面。
