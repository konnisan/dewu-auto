# 得物自动报名：类目与奖励筛选可靠性设计

## 目标

修复并验证产品类目和现金奖励范围筛选，使自动化只处理用户指定类目、且任务卡片上的“现金奖励”金额位于用户设置区间内的任务。测试覆盖全部产品类目和奖励边界，真机验证停在不可撤销报名确认之前。

## 已确认规则

- 奖励范围只读取任务卡片上的“现金奖励”金额，不使用商品价格、样品价值、报名人数或详情页中的其他数字。
- 区间包含最小值和最大值。例如设置 `30-99999` 时，`¥30` 和 `¥99999` 通过，`¥29.99`、`¥99999.01`、金额缺失或金额无法识别均跳过。
- 产品类目必须与前台设置的类目精确一致；不能因为任务列表已经出现就推断类目选择成功。
- 本轮真机矩阵测试不得执行不可撤销的最终报名确认。

## 当前证据与问题

在达人号真机、得物 5.89.0 和当前 APK 上，设置“鞋、30-99999”后：

- 顶部筛选栏显示“鞋”，证明本轮类目选择成功；
- 同屏任务包含 `¥25`、`¥30` 和 `¥20`；
- 自动化进入的是“巫六七德训鞋 W6792-p，现金奖励 ¥30”，没有进入 `¥20` 或 `¥25` 任务；
- 自动化在最终确认闸门暂停，未完成报名。

因此，这台设备没有复现“鞋未选中”或“30-99999 仍选择 ¥20”。但现有代码仅以筛选面板关闭且任务列表可见作为类目成功条件，无法排除其他设备、布局或页面加载时发生误报；现有扫描结果也没有完整展示实际金额与配置区间，使测试者难以区分旧 APK、相邻任务金额串读和真实筛选错误。

## 设计

### 任务卡片隔离解析

每个“报名”按钮只关联其所属任务卡片。解析器只能从该卡片边界内读取标题、现金奖励、报名人数、名额和截止时间，不得从父级任务列表或相邻卡片补充金额。

现金奖励解析要求金额与“现金奖励”标签属于同一卡片。若同一卡片存在多个人民币金额，只选择与“现金奖励”标签对应的金额；无法唯一确定时按“奖励无法识别”跳过。

### 奖励范围判断

启动任务时读取并标准化一次前台配置，之后整轮运行使用同一份最小值和最大值。每张卡片先完成金额解析，再使用包含端点的闭区间判断：

`minReward <= cashReward <= maxReward`

扫描结果必须展示任务名、解析到的现金奖励、当前配置区间和结论。例如：

- `现金奖励 ¥20，不在 ¥30-¥99999，跳过`
- `现金奖励 ¥30，位于 ¥30-¥99999，通过`
- `未识别到现金奖励，跳过`

### 产品类目选择与验真

打开筛选面板后，先在当前可见类目中按完整文字查找目标。目标不可见时，在类目横向容器内分段滑动并重新读取节点，直到找到目标或到达滑动上限。点击目标类目后点击“确定”。

筛选成功必须同时满足：

1. 筛选面板已经关闭；
2. 商单页顶部当前类目文字与配置值精确一致。

任务列表出现或刷新只能作为页面可用信号，不能替代类目验真。验真失败时重新打开筛选面板再尝试一次；第二次仍失败则安全停止，并明确显示“类目未生效”，不得继续扫描或报名。

### 可观测性

运行日志和 APK 扫描结果保留以下信息：

- 本轮固定配置：产品类目、最低奖励、最高奖励；
- 类目查找、滑动、点击和顶部验真的结果；
- 每张任务卡片的标题、卡片边界、现金奖励和通过/跳过原因；
- 进入详情的候选任务标题与现金奖励。

日志不得输出卡密、完整收货地址或其他敏感信息。

## 测试设计

### 自动化测试

产品类目覆盖：服装、美妆个护、3C数码、配件、箱包、手表、鞋、家居、食品饮料、其他。

奖励区间 `30-99999` 至少覆盖：

| 卡片内容 | 预期结果 |
| --- | --- |
| 现金奖励 ¥20 | 跳过 |
| 现金奖励 ¥29.99 | 跳过 |
| 现金奖励 ¥30 | 通过 |
| 现金奖励 ¥30.00 | 通过 |
| 现金奖励 ¥99999 | 通过 |
| 现金奖励 ¥99999.01 | 跳过 |
| 无现金奖励 | 跳过 |
| 相邻卡片分别为 ¥20 和 ¥30 | 只允许 ¥30 卡片通过 |
| 卡片内含报名 20/100 人及现金奖励 ¥30 | 按 ¥30 通过 |

类目选择测试覆盖目标初始可见、目标需要横向滑动、点击未生效后重试、顶部类目不匹配和目标始终未出现。

### 真机矩阵

依次使用全部十个产品类目运行。每轮记录配置、顶部实际类目、首屏任务金额判定和候选任务；一旦进入报名链路，只允许到达操作员最终确认闸门，随后取消并停止任务。若某类目暂时没有符合奖励范围的任务，以“类目已验真、所有可见任务均有明确跳过原因”为通过，不要求必须找到候选。

奖励范围至少真机验证三组：`30-99999`、仅含边界的窄范围，以及排除当前首屏所有任务的范围。真机结果与自动化测试结论必须一致。

## 错误处理与安全边界

- 类目无法精确找到、顶部类目验真失败、任务卡片边界无法确定或现金奖励无法唯一解析时，宁可跳过或停止，不猜测点击。
- 不通过固定屏幕坐标选择某个类目或任务。
- 测试过程中不点击最终“确认”报名按钮，不绕过验证码或平台风控。
- 页面结构变化导致全部任务无法解析时停止并保留截图、节点和脱敏日志。

## 验收标准

1. `30-99999` 时，任何 `¥20` 和 `¥25` 任务都不会进入详情，`¥30` 可以进入。
2. 相邻任务卡片的金额不会串读。
3. 全部十个产品类目均有自动化测试；真机每轮顶部类目与配置一致，否则明确失败并停止。
4. 扫描结果能直接说明任务实际金额、配置区间和通过或跳过原因。
5. 所有真机测试均停在不可撤销报名确认之前。

## 非目标

- 不按商品售价或样品价值筛选。
- 不新增奖励类型自动选择规则。
- 不改变屏蔽词的三个字段规则。
- 不在本轮测试中完成真实报名。
